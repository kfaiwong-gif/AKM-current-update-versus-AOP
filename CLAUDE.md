# CLAUDE.md

## Project Overview

**Jetronic FCST vs AOP Dashboard** — A single-file HTML application that compares sales forecast (FCST) data against annual operating plan (AOP/budget) data for the Jetronic/JetroS business unit. It covers fiscal years FY2026 (Apr 2026–Mar 2027) and FY2027 (Apr 2027–Mar 2028).

This is a client-side-only dashboard with no backend. All data processing happens in the browser via Excel file uploads.

## Key Concepts

### Data Flow
1. User uploads two `.xlsx` files via the Settings panel (gear icon)
2. **FCST file** (`FCST_JetroS_*.xlsx`): Contains forecast quantities (Kpcs) and amounts (mUSD) — parsed by `parseFCST()`
3. **AOP file** (`FCST_vs_Budget_JetroS_*.xlsx`): Contains budget quantities and amounts (mJPY) — parsed by `parseAOP()`
4. `mergeData()` combines both into the global data object `D`
5. All views re-render from `D`

### Global Data Object (`D`)
The central data structure with these keys:
- `D.meta` — FX rate, source info
- `D.summary` — FY-level totals (`fy26`, `fy27`): revenue, qty, variance, attainment
- `D.monthly[]` — Array of month objects with aggregated FCST/AOP values
- `D.customers[]` — Customer-level aggregation with nested `pn[]` (part number breakdown)
- `D.groups[]` — Product group aggregation
- `D.markets[]` — Market/segment aggregation
- `D.products[]` — Line-level detail with per-product `monthly{}` data

### Currency System
- Default currency is JPY (`CCY='jpy'`). Toggle to USD via header button.
- FX rate (default 150 JPY/USD) configurable in Settings panel.
- FCST amounts originate in USD, AOP amounts originate in JPY.
- Helper functions: `fmtRev()`, `fmtRevNum()`, `fmtRevK()`, `revSuffix()`, `revTickFn()`.

### Fiscal Year Definitions
- **FY26**: Apr 2026 – Mar 2027 (12 months)
- **FY27**: Apr 2027 – Mar 2028 (12 months)
- Month keys use `YYYY/MM` format (e.g., `2026/04`)
- Generated by `genMonths(year, startMonth, count)`

## Dashboard Views (6 Tabs)

| Tab | ID | Description |
|-----|----|-------------|
| Overview | `view-overview` | KPI cards, monthly bar chart, top customers, product group charts, monthly table (3 slides) |
| Monthly Trend | `view-monthly` | Full timeline chart (Apr 2025–Mar 2028) + detail table (2 slides) |
| Customers | `view-customers` | Sortable customer table with expandable P/N breakdown + top-15 chart |
| Product Groups | `view-groups` | Group-level FCST vs AOP chart + sortable table |
| Line Detail | `view-detail` | Paginated product-level table (25 rows/page) with search and group filter |
| Markets | `view-markets` | Market-specific drill-down: variance by month and by customer, both expandable |

## Presentation Mode

The app uses a 16:9 "deck" layout (`<div class="deck">`) that fills the viewport with letterboxing. Each tab view has multiple slides navigable via:
- Bottom nav bar (prev/next buttons + dot indicators)
- Keyboard: Arrow Right/Space = next, Arrow Left = previous

Slide state is tracked per tab in `slideState{}`.

## Excel File Format Details

### FCST File Structure
- Uses the **last sheet** in the workbook
- Data rows start at index 2 (after 2 header rows)
- Key columns: `r[0]`=type, `r[7]`=group, `r[9]`=product, `r[15]`=customer, `r[22]`=market, `r[93]`=FX rate
- Quantity rows: `type='Outgoing__c'`, `r[3]='販売計画'` — monthly values at cols 49–78
- Amount rows: `type='Amount__c'`, `r[3]='売上予想(金額)(mY,mD)'` — monthly mUSD at cols 49–78
- Covers 30 months: Jan 2026 – Jun 2028

### AOP File Structure
- Uses **Sheet1** (first sheet)
- Data rows start at index 3
- Key columns: `r[4]`=group, `r[5]`=product, `r[9]`=customer
- Quantity: cols 29–64 (36 months, Apr 2025 – Mar 2028)
- Amount (mJPY): cols 137–172 (same 36 months)

## CSS Architecture

Uses CSS custom properties for theming:
- `--fcst` (#1a7fd4, blue) — Forecast color
- `--aop` (#c94d1a, orange) — AOP/budget color
- `--pos` (#007a52, green) — Positive variance
- `--neg` (#c41740, red) — Negative variance
- `--mono` (DM Mono) — Data/numbers font
- `--sans` (DM Sans) — UI text font

CSS class conventions:
- `.kpi` — KPI cards with color variants (`.cb`, `.co`, `.cg`, `.cr`, `.cy`, `.cp`)
- `.tbl` — Data tables; `.tr`=right-align, `.tf`=forecast color, `.ta`=AOP color, `.tg`=green, `.tx`=red
- `.panel` — Content containers with `.ph` (header), `.pb` (body)
- `.cust-row` — Expandable table rows; `.pn-row` — Part-number sub-rows
- `.ov-pn-row` — Second-level expandable rows (customer→P/N in overview)

## Development Guidelines

- **Single-file architecture**: All HTML, CSS, and JS live in one file. Keep it that way.
- **No build system**: Open the HTML file directly in a browser. No bundler, no server needed.
- **Minified CSS class names**: Classes like `.hdr`, `.ph`, `.pb`, `.pt`, `.tbl` are intentionally short. Follow the existing naming convention.
- **Japanese labels**: Some UI labels and data field names are in Japanese (e.g., `販売計画`, `売上予想`). These correspond to Salesforce field names and should not be translated.
- **Chart.js patterns**: All charts share a common options object `CTX`. Destroy old chart instances before creating new ones to prevent memory leaks.
- **Data key format**: Products are keyed as `prod+'|'+customer`. Month keys are `YYYY/MM`.
- **Lazy tab initialization**: Tabs are only rendered on first visit (tracked in `tabInited{}`). Force re-init with `sw(tabName, true)`.
- **AOP amounts are in JPY**: Do not multiply by FX rate. FCST amounts are in USD and must be converted via `fusd * FX`.
